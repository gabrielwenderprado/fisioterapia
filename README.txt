COMO PUBLICAR NO GITHUB PAGES

1. Crie um repositório no GitHub, por exemplo: revisao-cinesioterapia.
2. Envie o arquivo index.html para a raiz do repositório.
3. Abra Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione a branch main e a pasta / (root), depois clique em Save.
6. Aguarde alguns minutos.

O endereço ficará parecido com:
https://SEU-USUARIO.github.io/revisao-cinesioterapia/

Recursos incluídos:
- resumo completo dos cinco materiais;
- 32 flashcards;
- banco de 100 questões;
- modo prova com 20 questões e nota de 0 a 10;
- 10 questões dissertativas com correção por palavras-chave;
- revisão de última hora;
- desempenho salvo no navegador;
- layout responsivo para celular.
